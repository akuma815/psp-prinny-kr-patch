## 타이틀 그래픽 PoC 교정 결과

`POC-TITLE-GRAPHICS-001` v1은 정적 미리보기와 Headless 부팅은 통과했지만 실제 PPSSPP 화면에서 글자가 깨졌다. 한 개 144색 CLUT를 16색 런타임 팔레트 뱅크 9개로 선택하는 구조에서, 전체 CLUT 기준 안티앨리어싱 인덱스를 사용한 것이 원인이었다. 정적 RGBA 디코드는 전체 CLUT를 보므로 정상처럼 보였지만 각 스프라이트가 활성 뱅크에서 같은 인덱스를 다른 색으로 해석했다. 따라서 v1의 화면 판정은 **FAIL**이다.

v2는 원본 영역의 주 사용 인덱스를 채움색으로 고정해 깨짐을 없애고 `데이터 로드`를 추가했지만, Regular 문구에도 1px 불투명 외곽선을 적용해 부제·메뉴·데이터 문구까지 Bold처럼 보였다. 또한 `데이터 로드`와 `데이터 교환`에 서로 다른 외곽선 인덱스를 써 두께가 달랐다. 이 구성은 사용자 관측으로 폐기했다.

v3는 `프리니` 세 글자를 아틀라스의 `[252,148]..[470,226]` 한 블록에 Bold 44px·15도로 렌더링했다. 실제 화면에서는 게임이 원본 `プ/リ/ニ/ー` UV 슬롯을 각각 따로 소비해 한 블록의 서로 다른 조각을 잘라 배치하므로 세 글자가 크게 어긋났다. 따라서 v3의 실제 화면 판정은 **FAIL**이다.

v4는 원본 UV 슬롯별 배치로 글자 식별에는 성공했지만 실제 화면에서 슬롯별 확대·회전 차이 때문에 크기와 각도가 달랐다. 이진 투명/불투명 가장자리는 계단처럼 우글거렸으며, 본체 연결 영역 밖에 있던 `プ` 반탁점 `(303,166)..(318,181)`과 `ニ` 아래 획 `(380,181)..(422,205)`도 남았다. 따라서 v4의 실제 화면 판정은 **FAIL**이다.

v5 실제 화면에서는 원문 잔재 제거는 확인됐지만 세 글자의 각도가 달랐고 `니`가 작았으며 제목·부제에 얇은 반투명 외곽선 단계가 더 필요했다. 따라서 v5는 실제 화면 FAIL로 닫았다.
