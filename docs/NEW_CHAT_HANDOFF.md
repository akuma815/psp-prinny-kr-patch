## 반드시 지킬 작업 규칙

1. 원본 ISO와 원본 추출 파일은 수정하지 않는다. 항상 복사본에서 작업한다.
2. 당분간 ISO를 만들지 않는다. 깨끗한 extracted 폴더를 복사한 PPSSPP 직접 실행용 폴더로 검증한다.
3. 텍스처 교체는 빠른 시각 검수용이다. 최종 누락 검사는 텍스처 교체를 끈 상태에서 한다.
4. 새 테스트 ISO를 만들게 되면 이전 테스트 ISO는 삭제한다. 원본 ISO는 절대 삭제하지 않는다.
5. 사용자가 수정한 CSV, JSON, 번역 PNG를 임의로 되돌리거나 덮어쓰지 않는다.
6. 작업이 끝날 때마다 관련 `docs/*.md`와 이 문서를 업데이트한다.
7. 확인된 사실과 추정을 구분한다. 인게임 확인 전에는 완료로 기록하지 않는다.
8. 사용자가 PPSSPP 실행과 화면 캡처를 담당한다. 불필요한 자동 실행과 반복 ISO 빌드를 피한다.

## 번역 및 문체 확정 사항

- `목도리`는 `머플러`로 번역한다.
- 프리니 말투는 문맥에 맞춰 `임다/임까`, `음다/슴다`를 자연스럽게 선택한다.
- 무조건 `음다` 또는 `슴다`로 통일하지 않는다.
- 승인된 예: `없슴까?`, `그렇게 쉽게 되진 않을 거야.`, `굳세게 살겠슴다.`
- 사용자가 직접 수정한 대사 예: `자, 기한은 내일 아침까지야.`
- 검토 대기열은 사용자가 여러 차례 검토 완료했으므로 최신 번역 파일을 정본으로 삼는다.

## 이미지와 ANIME.DAT

- ANIME.DAT에서 추출한 PNG는 영상 프레임 전체가 아니라 애니메이션/화면 구성에 쓰이는 텍스처 레코드와 아틀라스다.
- 따라서 한 화면이 여러 PNG 또는 여러 팔레트(CLUT) 레이어로 합성될 수 있다.
- 이미지 초벌 번역본은 `gallery\assets\translated`에 모여 있다.
- 검수 결과 파일:
  - `prinny-image-review-2026-07-24.json`
  - `prinny-image-review-2026-07-25.json`
- 일부 번역 이미지에는 일본어 잔재, 좌우/상하 반전, 회전, 잘림 문제가 남아 있다.
- 이미지와 동적 글자를 구분해야 한다. 매 프레임 내용이 바뀌는 글자 아틀라스는 PNG별 번역 대상이 아니다.

## stage_info.csv

- 사용자가 188개 항목의 번역을 완료했다.

  4. 포인터 테이블과 문자열 종료자를 확인한다.
  5. 첫 5개와 마지막 5개에 서로 다른 짧은 표식을 넣어 직접 실행 폴더에서 매핑을 검증한다.

- 데이터 로드/교환

- TIPS, 난이도 변경 설명, 저장 확인문

## 스테이지 결과 화면

미해결 사항:

- `클리어 시간 %02d′%02d″%02d`에서 시간 숫자와 트로피 그림이 겹침
- 사망 프리니 수 뒤의 단위가 `마리`가 아니라 한자처럼 표시됨
- 일부 결과 화면 영문 이미지가 남음

폰트에 문자가 없다는 가정만으로 처리하지 않는다. 실제 포맷 문자열, 제어 코드, 숫자 슬롯, 글리프 매핑을 확인한다. `마리`는 동적 단위 문자열을 직접 고친다.

## 기존 통합 ISO가 실패한 이유

- PPSSPP 텍스처 교체용 PNG가 게임 DAT에 자동 포함되는 것은 아니다.
- 여러 통합 스크립트가 서로 다른 베이스 트리와 작업 순서를 사용했다.
- 이미 수정된 빌드 트리에 다시 패치를 적용해 오염됐을 가능성이 있다.
- stage_info의 CSV 순서와 게임 레코드 순서가 일치하는지 검증하지 않았다.
