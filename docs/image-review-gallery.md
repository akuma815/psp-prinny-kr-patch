# 이미지 한글화 오프라인 검수 갤러리

최종 갱신: 2026-07-25

## 목적

게임을 처음부터 끝까지 플레이하거나 ISO를 다시 만들지 않고, 추출된 이미지 원본과 한글 초벌 번역본을 한 화면에서 비교·검수한다.

## 실행

다음 파일을 웹 브라우저로 직접 연다.

`work/live/image_first_pass_review/gallery/index.html`

웹 서버, 인터넷 연결, PPSSPP 및 ISO가 필요하지 않다. 갤러리는 `file://` 직접 실행에 맞춰 외부 라이브러리 없이 작성되었다.

## 제공 기능

- 번역 대상 66개 원본/번역본 나란히 비교
- 원본만, 번역만, 1×/2×/4× 확대 및 픽셀 보간 해제
- 이미지를 눌러 원본과 번역본을 투명도로 겹쳐 비교
- 자산 ID 검색, 자산 분류, PPSSPP 연결 상태, 중복 번역 필터
- `미검수`, `승인`, `수정 필요` 판정과 자산별 메모
- 판정과 메모의 브라우저 로컬 저장
- `검수 결과 내보내기`로 JSON 파일 저장

브라우저 저장소를 비우거나 다른 브라우저에서 열면 판정 상태가 이어지지 않으므로, 검수 종료 시 JSON을 내보낸다.

내보낸 JSON이 `work/live/image_first_pass_review`에 있으면 갤러리 생성기가 가장 최신
`prinny-image-review-*.json`을 자동으로 읽는다. 같은 자산 ID에 브라우저 로컬 판정이
없을 때 JSON의 상태와 메모를 초기값으로 표시한다.

## 갱신

전체 이미지 처리와 함께 갱신하려면 프로젝트 게임 폴더에서 실행한다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File `
  .\workspace\scripts\refresh_all_baked_graphics_preview.ps1 `
  -PpssppRoot 'H:\ppsspp'
```

이미지 매니페스트가 이미 최신이면 갤러리만 빠르게 다시 만든다.

```powershell
python .\workspace\scripts\build_image_review_gallery.py `
  --project-root .
```

생성 원본은 `workspace/review_gallery`, 생성 결과는 `work/live/image_first_pass_review/gallery`에 있다. 갤러리를 다시 생성해도 브라우저에 저장된 검수 판정은 자산 ID 기준으로 유지된다.

## 검수 원칙

갤러리에서 화면 범위, 잔재, 회전·반전, 글자 정렬, 외곽선, 깨짐을 먼저 일괄 검수한다. 실제 UV 조합, 동적 숫자·버튼·글자 레이어, 애니메이션 타이밍처럼 정적 PNG만으로 판단할 수 없는 항목만 PPSSPP 대표 장면에서 후속 확인한다.

| 수정 필요 | 33 |

수정 필요 33건은 다음 묶음으로 2차 생성본에 반영했다.

- `bg9802`: 원본 조작 안내 도형의 실제 좌표를 유지하고 내부만 재구성해 한글을 중앙 배치
- `bg9803`: 우측 상단 게임 회사 로고를 보존하도록 문자 제거 범위를 분리
- `anime20 r14`: 나무 간판 테두리를 보존하고 내부 목재색을 복원한 뒤 원래 글자 범위에 배치
- `anime92/93 t10~t23`: 28개 프레임에서 화자 명패 전체를 덮지 않고 명패 내부 글자와 대사만 교체
- `start anime00 r73`: 적 명칭을 원래 아틀라스의 우측·중앙·하단 셀 좌표에 다시 배치
- `start anime00 r87`: 리플레이·저장 원문 셀 전체를 지운 뒤 같은 셀에 한글을 재배치

이 단계는 ISO를 만들지 않았다. 갤러리의 기존 판정과 메모는 그대로 불러오며,
`수정 필요` 33개 항목만 번역 이미지를 다시 비교한 뒤 승인 여부를 갱신한다.
전체 대상 66/66, 원본/번역 크기 일치 66/66, 누락 0을 재확인했다.

수정 필요 32건은 `bg9802` 1건, `anime91` 1건, `anime20` 1건,
`anime92/93 t10~t23` 28건, 적 명칭 아틀라스 1건이다. 이번 생성본은 단색

이름표 내부와 전체 원문 대사 범위를 분리 복원해 일본어 잔재를 제거했다.

전체 66개 교체 PNG와 갤러리를 다시 생성했으며 원본/번역 크기 일치 66/66,
누락 0이다. PPSSPP 교체 텍스처만 갱신했고 ISO는 생성하지 않았다. 다음 검수는
JSON에서 `needs_fix`였던 32개 항목만 확인하면 된다.
