# 프리니 DLC 번역 입력

## 파일

| 파일 | 대상 | 행 수 |
| --- | --- | ---: |
| `dl0000_ddem.csv` | 마왕성·플론 DLC 대사 | 29 |
| `dl0001_ddem.csv` | 유령섬·마로네 DLC 대사 | 23 |
| `dl0002_ddem.csv` | 연무성·아사기 인형 DLC 대사 | 15 |
| `dlc_stage_info.csv` | DLC 선택 화면 제목·설명 | 33 |

DDEM은 1레코드=1행이다. 화면에 표시되는 순서대로 `ja_speaker`,
`ja_line_1`, `ja_line_2`, `ja_line_3`를 읽을 수 있다. 빈 줄도 원본 슬롯으로
보존된다.

## 수정할 열

DDEM CSV에서는 다음 열만 수정한다.

- `ko_speaker`
- `ko_line_1`
- `ko_line_2`
- `ko_line_3`
- `status`
- `notes`

`dlc_stage_info.csv`에서는 다음 열만 수정한다.

- `ko`
- `status`
- `notes`

나머지 ID·오프셋·바이트 한도·원문·원본 바이트 열은 보호 필드다. 행을 추가,
삭제, 재정렬하지 않는다. CSV는 UTF-8 BOM을 유지한다.

번역을 마친 행은 자동 검사를 통과하기 전까지 `needs_review`, 검토와 바이트 한도
검사를 통과한 뒤 `complete`로 바꾼다. 빈 DSTI 슬롯은 `empty`로 유지한다.

## 고정 슬롯 한도

- 화자: 최대 16바이트
- 본문 각 줄: 최대 34바이트
- DLC 제목·설명 각 줄: 최대 32바이트

한글은 현재 사용자 정의 CP932 코드에서 음절당 2바이트다. 실제 빌드에서는 최종
987자 매핑을 고정하고 DLC 신규 글자만 추가한다. 아직 매핑되지 않은 글자나 한도
초과는 빌드 오류로 처리한다.

## 장면 흐름

- `DL0000`: 플론과 전투 전 대화, 전투 후 플론·에트나 대화
- `DL0001`: 마로네가 프리니를 오해하는 전투 전 대화, 애쉬 등장 뒤 전투 후 대화
- `DL0002`: 아사기 인형 스테이지의 짧은 공격·피격·이벤트 대사

시작 직후에는 별도 대사가 없다는 사용자 실행 결과가 있다. DDEM 대사는 보스
조우·전투 중·클리어 뒤 이벤트에서 소비되는 것으로 판정한다.

## 원문 주의점

`DL0000` 첫 레코드 `0x55F0`의 원시 CP932 디코드는
`むあちなすわ～いっ！！`다. 문맥상 `お待ちなさ～いっ！！` 계열일 가능성이
높지만, 실제 화면에서 원본 글리프 출력을 확인하기 전에는 보호 원문을 고치지
않는다. 번역 판단은 `notes`에 근거를 남긴다.

## 재추출

```powershell
$env:PYTHONIOENCODING='utf-8'
python .\workspace\scripts\export_dlc_text.py
```

재추출은 지원 EDAT에서 보호 필드를 다시 만들고 위 수정 가능 열만 승계한다.
